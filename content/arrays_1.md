# Introduction to Arrays

An array is one of the most fundamental data structures in computer science. It allows you to store a collection of items, typically of the same data type, under a single name. Think of it like a row of mailboxes, where each mailbox has a sequential number, making it easy to find exactly what you're looking for.

### Memory Allocation

When you create an array, the computer sets aside a contiguous block of memory. This means all the elements are stored right next to each other. Because of this layout, the computer can instantly calculate exactly where any item is located using simple math, which is why accessing an array element by its index is incredibly fast.

### Indexing

Arrays are typically zero-indexed, meaning the first element is at index 0, the second is at index 1, and so on. If you have an array of five elements, the indices will range from 0 to 4. Remembering to start at zero is a common stumbling block for beginners!
